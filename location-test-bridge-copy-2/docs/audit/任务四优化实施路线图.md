# 《任务四优化实施路线图》

审计日期：2026-10-11  
原则：小步、可回退、每批可独立验收；已经成熟的教学流程不重做。

## 总体策略

当前没有P0阻断问题，因此不建议以“重构任务四”为名开启大批量修改。后续应先做范围很小、验证明确的修正，再单独安排S4-12视觉补完。每批都应保留现有存档版本，并用先南北/先东西两条路径做回归。

## 第1批｜进度菜单显示一致性

目标：完成用户已确认的“任务四下显示真实定位测试，且不列城市名”。

范围：

- 调整任务四完成行的展开/只读子项显示。
- 将默认节点文案从“真实定位测试·北京与里约热内卢”改为“真实定位测试”。
- 不改变节点值、城市完成数组、任务四完成状态或存档结构。

对应问题：T4-AUD-003。  
验收：进行中、完成后、刷新恢复后三种菜单状态都显示一致；任务一至三菜单无变化。

## 第2批｜教学球命中体验

目标：减少学生“看见度数、点击文字却没选中”的挫折。

范围：

- 让20°N、120°E等当前可选标签复用对应线条的选择处理。
- 保留线条原命中区、错误反馈、拖动阈值和球面判定。
- 不自动寻找目标线，不扩大正确判定角度，不改变学习难度。

对应问题：T4-AUD-004。  
验收：纬度、经度、双线实验三处分别验证标签点击、线条点击、拖动后释放；错误线仍可重试。

## 第3批｜真实地球仪回归与触屏专项

目标：把目前静态检查通过、但未在真实触屏上验证的操作补齐为正式验收证据。

范围：

- 在iPad/触控大屏实测单指旋转、双指捏合、松手状态清理。
- 检查0.6倍、1倍、2倍下北京/里约/珠海点击误差和标记遮挡。
- 本批默认不改缩放速度、上下限或投影；只有复现问题才另开修复批次。

对应问题：无确定Bug，是未验证项。  
验收：录制两城市和珠海的触屏操作；退出/重进无残留触点状态。

## 第4批｜S4-09～S4-11视觉收束

目标：让“测试结束→寻找珠海→锁定→等待启动”的视觉节奏更集中。

范围：

- 收紧S4-11中央设备内部纵向留白。
- 为S4-12启动前统一清退旧定位任务文字，避免与锁定反馈叠层。
- 不改S4-09两段文字、1秒等待、S4-10定位算法、S4-11的2秒停留和按钮逻辑。

对应问题：T4-AUD-002、T4-AUD-005。  
验收：1280×720、1366×768、1920×1080三档；中央面板内容完整，启动返航前后无旧信息残留。

## 第5批｜S4-12镜头推进与珠海地图补完

目标：完成目前唯一明确未达到设计目标的高潮演出。

最小可行范围：

1. 继续复用 `task4/real-earth-globe.js` 的视角和缩放接口。
2. 启动时先建立可辨认的全球宽景，不依赖玩家启动前恰好处于什么视角。
3. 设置三个显式镜头状态：全球宽景→中国南部→珠海近景；各段使用同一动画令牌和取消机制。
4. 准备一份本地、轻量、经过确认的珠海区域轮廓/海岸简化资源；没有可信数据前继续标“示意”，不要用任意岛形冒充真实地图。
5. 从球体近景交叉淡入珠海地图，先点亮抵达点，再显示“返航成功”和结尾打字。

后期精修（不纳入最小完成）：

- 镜头缓动曲线、景深、路线光效、城市纹理、音效层次。
- 更高精度的珠海海岸线和岛屿细节。

对应问题：T4-AUD-001。  
验收：从任意真实地球视角启动都能看出三段尺度变化；不黑屏；北京/里约淡出、珠海标记保留；最终图明确标注珠海且不冒充在线地图。

## 第6批｜最终回归、可访问性和低风险清理

目标：完成全流程收尾，不触碰成熟剧情结构。

范围：

- 设备收起时同步隐藏辅助技术树中的面板内容，修复过期状态暴露。
- 为正式任务四入口增加“不可进入旧版先纬线流程”的自动化断言。
- 确认旧流程无依赖后，另行决定是否删除；不与S4-12视觉开发混在同一批。
- 对S4-13只做回归，不改四项成果、最终坐标或展示节奏。

对应问题：T4-AUD-006、T4-AUD-007。  
验收：辅助技术只读到当前可见设备状态；正式任务四入口永远进入双方向自由选择；最终档案继续可恢复。
